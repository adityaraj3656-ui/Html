About This Project

This Plot Dashboard is designed to display data in a visual and understandable format. It uses three types of plots: bar plots, line plots, and pie plots.

The bar plot compares marks across different subjects. The line plot shows how attendance changes over time. The pie plot represents the distribution of student performance across different categories.
